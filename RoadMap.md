# Archimedes Roadmap

This document outlines the development direction and major milestones of the Archimedes platform.

## Phase 1 — Initial Product Validation

**Status: In progress**

- [x] Develop the first functional version for a confectionery business.
- [x] Implement order management.
- [x] Implement product and pricing management.
- [ ] Implement delivery scheduling.
- [ ] Implement sales reporting.
- [x] Validate the platform with real businesses.

## Phase 2 — Platform Foundations

- [x] Establish the multi-tenant architecture.
- [x] Implement business registration and authentication.
- [ ] Establish the Sketch selection system.
- [ ] Establish the independent module architecture.
- [ ] Implement subscription and payment management.

## Phase 3 — First Business Verticals

- [x] Confectionery Sketch.
- [ ] Mobile Phone Retail Sketch.
- [ ] Bakery Sketch.
- [ ] Snack Bar and Restaurant Sketch.

## Phase 4 — Business Management Modules

- [ ] Inventory management.
- [ ] Employees management.
- [ ] Suppliers and purchasing.
- [ ] Order printing.
- [ ] Scale integration.
- [ ] Scheduling and appointments.

## Phase 5 — Expansion

- [ ] Expand the Sketch ecosystem.
- [ ] Introduce custom Sketch development.
- [ ] Implement fiscal document integrations.
- [ ] Expand payment integrations.
- [ ] Improve scalability and platform infrastructure.

---

*This roadmap is subject to change as the platform evolves and new business requirements are identified.*
